# DeepISP: Toward Learning an End-to-End Image Processing Pipeline

## 精读版学习目标

DeepISP 要解决的问题不是单纯去噪，而是“能不能把传统 ISP 的多步人工管线变成一个可学习系统”。读这篇时要不断对照 stage1：BLC、Demosaic、AWB、CCM、Gamma、Tone Mapping 这些显式模块，如果被一个网络吞掉，会得到什么好处，又会失去什么可控性？

## 端到端 ISP 的核心矛盾

传统 ISP 的优点是可解释、可调参、可分模块定位问题。缺点是模块之间互相影响，手工规则多，针对不同相机和场景需要大量调校。端到端 ISP 的优点是可以直接优化最终输出，缺点是中间过程不透明，失败时很难知道是颜色、曝光、噪声还是纹理出了问题。

DeepISP 处在这个矛盾的早期探索阶段。它不是最终答案，但能帮你理解 AI-ISP 为什么吸引人，以及为什么工业系统不会轻易完全放弃传统模块。

## 局部分支和全局分支的直觉

ISP 既有局部问题，也有全局问题。局部问题包括噪声、边缘、纹理、局部伪色；全局问题包括白平衡、曝光、整体对比度和色彩风格。如果网络只看小 patch，很难判断整张图偏暖还是偏冷；如果只做全局调整，又处理不了局部纹理。

因此 DeepISP 类方法通常会同时考虑局部特征和全局上下文。这一点对你设计 stage2 模型很重要：低光增强和 AI-ISP 不只是“卷积层越多越好”，还要让模型看到足够的全局信息。

## 和传统模块怎么对应

可以粗略对应为：

```text
局部恢复：denoise / demosaic / sharpening / artifact removal
全局调整：AWB / exposure / CCM / tone mapping / style
```

如果模型输入已经是 RGB，那么它更多是在学习后处理增强；如果输入是 RAW 或 packed RAW，它才更接近学习 ISP 前中段。

## 和本项目的具体练习路线

1. 在 `stage1_soft_isp` 导出 rawpy 参考图和你自己的 pipeline 输出，作为 paired 数据雏形。
2. 在 `stage2_ai_isp` 训练一个小 image-to-image 模型，让它从你的简化 pipeline 输出拟合 rawpy 输出。
3. 加一个全局统计分支：输入图像均值、方差、灰世界白平衡估计，观察颜色是否更稳定。
4. 写失败案例：端到端模型在哪些区域比传统 pipeline 好，在哪些区域更不可控。

## 面试级复述

可以这样复述：DeepISP 探索用神经网络学习端到端图像处理管线，将传统 ISP 中局部恢复和全局颜色/曝光调整合到一个可训练框架里。它的价值是展示 AI-ISP 可以直接优化最终图像质量；局限是可解释性、跨相机泛化和部署可控性弱。工程上更现实的方向往往是传统模块和学习模块混合。

## 为什么要读这篇

DeepISP 是理解 AI-ISP 的早期代表：它不是只做去噪，而是尝试学习从低质量相机输入到高质量输出的端到端 ISP 映射。读它可以帮助你理解“用神经网络替代传统 ISP”最早面对的几个问题：输入表示、颜色保真、局部细节、全局风格和可解释性。

## 背景问题：它解决了什么痛点

传统 ISP 每个模块都有手工规则，模块之间误差会累积。比如去噪过强会影响 demosaic 和锐化，颜色校正不准会让后续增强继续放大色偏。DeepISP 尝试把这些手工模块压缩到一个学习系统中，让网络直接优化最终视觉质量。

## 初学者预备知识

需要了解 CNN、残差连接、U-Net/encoder-decoder 思想、L1/L2 损失、感知质量和颜色空间。建议先完成 stage2 的 toy RGB denoise，再读这篇。

## 核心思想一句话

用端到端 CNN 学习传统 ISP 多模块组合的整体映射，而不是逐个手写每个处理步骤。

## 方法原理详解

DeepISP 的核心是把局部修复和全局颜色/风格调整结合起来。局部网络负责纹理、噪声、细节等空间变化明显的问题；全局分支则学习整张图的颜色和曝光倾向。这样设计的原因是 ISP 同时包含局部算子和全局决策：降噪、去马赛克偏局部，白平衡、色彩风格、曝光调整偏全局。

对初学者来说，重点不是照抄结构，而是理解网络为什么需要同时看局部 patch 和全局上下文。只用小卷积核堆叠，很难稳定决定整张图的色温和曝光；只做全局调整，又无法恢复局部细节。

## 网络结构或算法流程

1. 输入低质量图像或相机处理前图像。
2. 局部分支提取空间特征，处理纹理、噪声和细节。
3. 全局分支估计图像级调整信息。
4. 融合局部和全局特征。
5. 输出增强后的图像。

## 损失函数 / 数据集 / 训练方式

论文使用成对数据进行监督训练，目标是让网络输出接近高质量参考图像。通常需要像素级损失，并可能结合颜色或感知相关约束。阅读时要关注训练数据是否真实代表 RAW 到 RGB 的相机链路，因为数据分布决定模型学到的是“ISP”还是“后期滤镜”。

## 实验结果如何理解

实验结果应从颜色、噪声、细节和自然度四个角度看，而不是只看 PSNR。端到端方法可能在整体视觉上更好，但也可能产生颜色漂移和不可解释失败。

## 优点

- 清楚展示了 AI-ISP 的端到端方向。
- 把局部恢复和全局调整放在一个框架里。
- 适合作为 stage2 从去噪走向完整 ISP 学习的桥梁。

## 局限

- 早期 CNN 方法，结构和数据规模不如后续 Transformer/Diffusion。
- 对真实 RAW、相机元数据和部署约束讨论有限。
- 端到端可解释性弱，调试成本高。

## 和当前项目 stage1-stage4 的对应关系

- stage1_soft_isp：可对照传统模块，看网络替代了哪些显式步骤。
- stage2_ai_isp：对应从 RGB denoise 扩展到 image-to-image ISP。
- stage3_cpp_isp：可把传统模块作为网络前后处理或 baseline。
- stage4_deploy_isp：端到端模型部署需要严格对齐输入归一化、颜色空间和输出范围。

## 可以在本项目中复现或简化实现的练习

1. 在 stage2 中把 TinyCNN 从去噪改成“伪 RAW/RGB 输入 -> rawpy 风格参考输出”的小任务。
2. 增加一个全局分支，输入整图平均颜色和曝光统计，观察是否改善色偏。
3. 用 stage1 输出作为传统 baseline，比较端到端模型在哪些场景失败。

## 阅读后应该掌握什么

你应该能说明：AI-ISP 不是简单把每个模块换成 CNN，而是要重新思考局部恢复、全局颜色和数据监督之间的关系。
