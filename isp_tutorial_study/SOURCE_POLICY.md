# 来源、证据等级与时效规范

本规范用于第 17–27、35 章，以及任何涉及产品参数、厂商内部架构、标准版本和“最新趋势”的内容。

## 证据等级

| 标签 | 含义 | 可以如何使用 |
|---|---|---|
| `[S1 官方/标准]` | 厂商产品简报、标准正文、官方开发文档 | 可作为公开事实，但仍需保留日期和适用型号 |
| `[S2 论文/专利]` | 同行评审论文、作者预印本、公开专利 | 可描述方法，不等于量产产品一定采用 |
| `[S3 第三方实测]` | 可复现实测、拆解、公开 benchmark | 可描述观察结果，不能直接推断内部结构 |
| `[S4 合理推断]` | 根据公开现象和工程常识推断 | 必须明确假设，不得写成“采用了” |
| `[S5 厂商宣传]` | 营销页、发布会口径、未公开测试方法的倍数 | 只用于理解定位，不能跨平台直接比较 |
| `[待核实]` | 找不到可靠公开依据或来源相互冲突 | 不进入结论、计算题或选型依据 |

## 每条产业资料至少记录


## 时效规则

- 禁止无日期地使用“最新”“当前最先进”“业界领先”。
- 厂商对比默认每 6 个月复查一次；标准、SDK 和软件接口默认每 12 个月复查。
- 旧产品资料可以保留，但标题应写“历史案例”或“截至 YYYY-MM”。
- 峰值 TOPS、像素率和功耗不能直接代表端到端相机质量或持续性能。
- “支持某功能”不代表所有终端都启用；平台能力、OEM 配置和软件版本必须分开。

## 已确认的代表性勘误

- Bayer RAW 是 CFA 交错采样的马赛克，不是完整 RGB。
- 理想 50Hz 电源下常见光强周期约 10ms，60Hz 下约 8.33ms；LED/PWM 仍须实测。
- Apple A17 Pro 的具体 ISP 流水级数、内部 cache、专用总线宽度和单核 MAC 数没有足够公开依据，本课程归为 `[待核实]`。
