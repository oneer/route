# 第15章：计算摄影与高级ISP功能



### 1. 本章先解决什么问题

传统 ISP 大多围绕单帧 RAW 到 RGB/YUV 的流水线展开：校正、去噪、去马赛克、颜色、tone、锐化。计算摄影的出发点是：单次曝光、单个镜头、单帧图像的信息有限，但相机系统还可以利用时间、多摄、运动、深度、IMU、语义和学习模型，输出超出单帧传统 ISP 能力的图像。

本章最小链路是：

```text
输入：连续多帧图像、多摄图像、IMU/陀螺仪、深度/视差、语义 mask、用户触发时刻
处理：帧选择、配准、运动估计、融合、去鬼影、超分、EIS、景深合成、散景、夜景增强、去模糊
输出：更稳、更亮、更清晰、更高分辨率、更有景深效果或更适合任务的图像/视频
```

读完本章，至少要能回答：

- 计算摄影和传统 ISP 的边界在哪里。
- 多帧为什么能提升 SNR、动态范围和分辨率。
- 配准失败为什么会造成鬼影、重影和伪细节。
- EIS 为什么会牺牲视场。
- 超分、去模糊、AI 增强为什么可能 hallucinate。
- 高级功能为什么会带来缓存、延迟、功耗和发热压力。

### 2. 计算摄影的核心直觉：多拿信息，多做重建

传统相机主要依赖光学系统和单次传感器采样。计算摄影则把相机看成“采集 + 计算”的系统。

它常用的信息来源包括：

| 信息来源 | 能帮助什么 | 典型功能 |
|---|---|---|
| 多帧时间信息 | 降噪、HDR、超分、去模糊 | 夜景、HDR+、burst denoise |
| 多摄像头 | 深度、视角、变焦、融合 | 人像散景、多摄融合 |
| IMU/陀螺仪 | 相机运动估计 | EIS、防抖、去模糊 |
| 深度/视差 | 前景背景分离 | 计算散景、AR、分层增强 |
| 语义分割 | 按内容调参 | 天空、肤色、文字、道路增强 |
| 学习模型 | 复杂先验和恢复 | AI denoise、SR、暗光增强 |

一句话：

```text
传统 ISP 更像“把一帧图处理好”。
计算摄影更像“用整个成像系统的信息重建一张更好的图”。
```

但计算摄影不是魔法。多拿信息的代价是：更多内存、更多算力、更多延迟、更多失败模式。

### 3. 多帧平均为什么能降噪

如果多帧拍到的是同一个静态场景，真实信号大致相同，随机噪声每帧不同。把 `N` 帧对齐后平均，随机噪声标准差大约会下降：

```text
noise_std_after_average ≈ noise_std_single_frame / sqrt(N)
```

例子：

```text
单帧噪声标准差 = 12
平均 4 帧后 ≈ 12 / 2 = 6
平均 9 帧后 ≈ 12 / 3 = 4
```

这就是夜景、多帧降噪、burst photography 的基础。Google HDR+ 相关论文把 burst photography 用在移动设备低光和高动态范围场景中，核心也是利用多帧短曝光来降低噪声并避免长曝光手抖。

但这个公式有一个前提：帧之间必须对齐，而且场景不能乱动。如果直接平均错位图像，噪声可能下降，但边缘会重影，运动物体会变成半透明。

### 4. 配准：计算摄影最关键也最容易失败的步骤

配准 registration 是把多帧或多摄图像对齐到同一个参考坐标系。

常见方法：

- 全局变换：平移、旋转、仿射、单应性 homography。
- 块匹配：为每个块估计运动向量。
- 光流：估计像素级运动场。
- 特征匹配：检测角点/特征点再拟合变换。
- IMU 辅助：用陀螺仪估计相机旋转。
- 深度辅助：用深度把视角差异解释成几何变换。

配准失败的典型原因：

- 物体运动和相机运动混在一起。
- 低纹理区域找不到稳定匹配。
- 高噪声或低光让特征不可靠。
- rolling shutter 让每一行时间不同。
- 多摄视角差异造成遮挡和透视变化。
- 反光、透明物体、重复纹理导致错误匹配。

所以多帧算法通常还需要运动 mask、置信度、outlier rejection 和 deghost 策略。

### 5. EIS：牺牲视场换稳定

EIS 是 Electronic Image Stabilization，电子防抖。它通过估计相机运动，让输出画面看起来更稳定。

基本流程：

```text
输入帧 + IMU/图像运动估计 -> 原始相机轨迹 -> 平滑轨迹 -> 计算补偿变换 -> warp/crop 输出
```

为什么 EIS 要裁剪视场？因为如果相机向右抖，稳定输出需要把图像内容向左移动；移动后边缘会露出空白。为了不露边，系统要预留 overscan 区域：

```text
传感器采集更大画面 -> 输出中间裁剪窗口 -> 裁剪窗口随运动移动
```

代价：

- 视场变窄。
- 有效分辨率下降。
- warp 插值可能损失细节。
- 低光下运动估计更难。
- rolling shutter 需要更复杂校正。

EIS 和 OIS 不同。OIS 是光学/机械防抖，通过移动镜头或传感器补偿抖动；EIS 是数字后处理。很多产品会结合 OIS、EIS 和 IMU。

### 6. 超分辨率：不是简单放大

超分辨率 Super-Resolution 的目标是从低分辨率观测恢复更高分辨率图像。

单帧 SR：

```text
一张低分辨率图 -> 利用图像先验或神经网络 -> 生成高分辨率图
```

多帧 SR：

```text
多张有亚像素位移的低分辨率图 -> 配准 -> 融合到高分辨率网格 -> 重建细节
```

多帧 SR 的真实优势来自亚像素采样差异。比如手持拍摄时，相机自然微小抖动会让同一场景落在传感器不同亚像素位置上；如果能精确配准，就相当于获得了更多采样。

但 SR 有风险：

- 配准错会产生重影和锯齿。
- 单帧 AI SR 可能 hallucinate 出不存在的纹理。
- 过强锐化会产生 ringing。
- 文字、车牌、工业检测等场景不能随便生成“看似合理”的细节。
- 多帧 SR 需要帧缓存、运动估计和更高延迟。

### 7. 夜景模式：多帧、短曝光和计算融合

夜景拍摄的问题不是单一噪声，而是一组矛盾：

- 光少，SNR 低。
- 曝光长会手抖和运动模糊。
- 曝光短噪声大。
- 高 ISO 会放大噪声。
- 暗部需要拉亮，高光又不能爆。

现代夜景通常用 burst：

```text
按快门前后缓存多帧 -> 选帧 -> 对齐 -> 多帧降噪/融合 -> 局部 tone/颜色/锐化 -> 输出
```

Learning to See in the Dark 这类论文展示了深度学习可以直接从极低照度 RAW 恢复可见图像，但工程上仍要面对真实噪声、运动、颜色偏差、过拟合、延迟和功耗。

夜景模式常见失败：

- 人物或树叶运动产生鬼影。
- 暗部被涂抹成油画。
- 高光灯牌溢出。
- 颜色变脏或偏色。
- 输出和预览差异很大。
- 长时间处理导致发热和等待。

### 8. 计算散景：深度错了，边缘就会假

计算散景 portrait/bokeh 的目标是模拟大光圈浅景深：主体清晰，背景虚化。

基本流程：

```text
输入图像 -> 估计深度/前景 mask -> 分离主体和背景 -> 按深度渲染模糊 -> 边缘融合 -> 输出
```

深度来源可能是：

- 双摄视差。
- dual pixel 相位差。
- ToF/结构光。
- 单目深度神经网络。
- 语义分割辅助。

最难的是边缘：

- 头发、透明物体、眼镜、宠物毛发。
- 前景和背景颜色相近。
- 细小孔洞和半透明区域。
- 深度估计在遮挡边界不连续。

如果 mask 错，背景可能有一圈没虚化，或者主体边缘被抹掉。好的散景不只是把背景高斯模糊，还要模拟景深层次、光斑形状、遮挡关系和边缘过渡。

### 9. 景深扩展：让不同焦平面都清楚

景深扩展 focus stacking 和计算散景方向相反。散景是让背景虚，景深扩展是让不同距离都清楚。

基本流程：

```text
拍多张不同对焦距离图 -> 计算每个区域清晰度 -> 选择最清晰区域 -> 融合成全焦图
```

清晰度测度可能来自：

- 局部梯度。
- Laplacian 能量。
- 高频能量。
- 对比度。
- 学习型清晰度估计。

失败模式：

- 对焦帧之间视角或放大率变化。
- 物体运动。
- 决策图边界不平滑。
- 景深合成边缘出现拼接痕迹。

显微、工业检测、手机微距和文档拍摄都可能用到类似思想。

### 10. 去模糊：恢复丢失信息很难

运动模糊来自曝光期间相机或物体运动。简化模型：

```text
blurred = sharp image * blur kernel + noise
```

去模糊要反推 sharp image 和 blur kernel。这是病态问题，因为高频细节已经被模糊削弱，还混有噪声。

常见路线：

- 非盲去模糊：已知 blur kernel，恢复图像。
- 盲去模糊：kernel 也未知，更难。
- IMU 辅助：用陀螺仪估计相机运动。
- 多帧去模糊：用短曝光/多帧补充信息。
- 学习型去模糊：从数据学习恢复。

风险：

- ringing。
- 过锐化。
- 纹理 hallucination。
- 噪声被放大。
- 对运动物体和背景使用同一 kernel 失败。

因此，防抖和短曝光策略常常比事后去模糊更可靠。

### 11. 语义感知 ISP：按内容调图

高级 ISP 不一定全图使用同一参数。语义信息可以告诉系统哪里是天空、皮肤、草地、道路、文字、脸、车牌。

可能策略：

- 人脸区域保肤色、控制磨皮和锐化。
- 天空区域降噪更强，避免色带。
- 文字/车牌区域保边缘和对比。
- 道路/车道线区域保证检测可见性。
- 夜景灯牌区域控制高光和饱和。

风险：

- 语义分割错会局部调错。
- 边界过渡不自然。
- 视频中 mask 抖动造成闪烁。
- 对机器视觉任务改变特征分布。
- 不同人群肤色、公平性和审美偏差问题。

语义 ISP 的关键不是“识别出来就调”，而是要有置信度、时域稳定、边界融合和失败兜底。

### 12. AI 增强和 Hallucination

AI 图像恢复可能在 denoise、SR、deblur、low-light、HDR、face enhancement 中表现很好，但必须理解 hallucination 风险。

hallucination 指模型生成看起来合理、但不一定真实存在的细节。例如：

- 纹理被补成网络常见样式。
- 字母或数字被改错。
- 车牌字符变形。
- 医学/工业图像出现虚假结构。
- 人脸细节被美化但不真实。

对消费摄影，适度 hallucination 可能被认为好看；对测量、安防、车载、工业检测，它可能是严重问题。

因此计算摄影要分场景评价：

```text
人看照片：主观自然、细节、噪声、肤色。
机器看图：检测精度、定位稳定、可解释性、不要伪造关键证据。
```

### 13. 高级功能的系统代价

计算摄影通常比传统单帧 ISP 更贵：

- 多帧缓存增加内存。
- 配准和光流增加算力。
- AI 模型增加 NPU/GPU/DSP 负载。
- 多帧处理增加延迟。
- 长时间运行增加功耗和发热。
- 预览和最终成片可能不一致。
- 用户按快门前后的帧选择需要复杂队列。

一个典型拍照系统可能有：

```text
预览流：低延迟、稳定、较低功耗
拍照流：高画质、多帧、可接受更高延迟
视频流：连续实时、热稳定要求高
AI/机器视觉流：固定输入格式、任务指标优先
```

同一个算法在这些流里的策略不一定相同。

### 14. 最小可验证实验

实验 1：两帧平均和配准。

1. 准备两张轻微位移的同一场景图。
2. 直接平均。
3. 先估计平移并配准，再平均。
4. 对比噪声下降和边缘重影。

实验 2：多帧 SNR。

1. 生成同一干净图的 1、2、4、8 帧噪声版本。
2. 对齐后平均。
3. 测量噪声标准差是否接近 `1/sqrt(N)` 下降。
4. 观察细节是否被平均糊掉。

实验 3：EIS 视场损失。

1. 选一段抖动视频。
2. 估计帧间平移。
3. 用不同裁剪比例做稳定。
4. 比较稳定程度和视场损失。

实验 4：超分 hallucination。

1. 找含文字或规则纹理的低分辨率图。
2. 分别用双三次和 AI SR 输出。
3. 放大看细节是否真实一致。
4. 记录哪些区域看起来更锐但不可信。

实验 5：散景边缘。

1. 准备一张有头发/栏杆/透明物体的人像或物体图。
2. 用不同质量的 mask 做背景模糊。
3. 对比边缘残留、主体误虚化、背景漏虚化。
4. 观察 mask feathering 和深度边界的影响。

### 15. 错误现象排查表

| 现象 | 可能原因 | 排查方向 |
|---|---|---|
| 多帧后边缘重影 | 配准失败或运动物体未剔除 | 看运动 mask、光流/块匹配置信度 |
| 夜景像油画 | 降噪/融合过强，纹理被抹 | 降低融合强度，检查 detail layer |
| 超分细节假 | 模型 hallucination 或过锐化 | 看文字/规则纹理，和原始信息对照 |
| EIS 后视角变窄 | overscan/crop 过大 | 调裁剪比例和稳定强度 |
| EIS 边缘变形 | warp 模型或 rolling shutter 处理不足 | 检查 IMU 同步和变换模型 |
| 散景边缘假 | 深度/mask 错误 | 看前景 mask、边界融合和透明区域 |
| 焦点堆叠拼接痕 | 清晰度决策图不平滑 | 平滑决策图，检查帧间视角变化 |
| 去模糊有 ringing | kernel 错或正则化不足 | 降低锐化/反卷积强度 |
| 视频增强闪烁 | 参数或语义 mask 帧间抖动 | 做时域平滑和置信度过滤 |
| 发热后效果下降 | 热管理触发降级 | 查看功耗、温度和模块开关策略 |

### 16. 常见误区

- 误区 1：多帧一定比单帧好。只要配准失败，多帧就可能更糟。
- 误区 2：AI SR 生成的细节都可信。看起来锐不等于真实。
- 误区 3：EIS 是免费稳定。它会牺牲视场、分辨率、边缘质量和延迟。
- 误区 4：夜景只是把图拉亮。夜景要处理噪声、运动、HDR、高光和颜色。
- 误区 5：散景只要背景模糊。关键在深度边界、遮挡、光斑和过渡。
- 误区 6：计算摄影只看成片。预览一致性、快门延迟、发热和功耗同样重要。
- 误区 7：消费照片指标可直接用于机器视觉。机器任务更怕 hallucination 和特征分布变化。

### 17. 学习优先级

必须掌握：

- 多帧平均提升 SNR 的 `1/sqrt(N)` 直觉。
- 配准、运动估计、运动 mask、deghost 的作用。
- EIS 的轨迹平滑、warp、crop/overscan。
- 单帧 SR、多帧 SR 和 hallucination 风险。
- 夜景多帧、计算散景、景深扩展、去模糊的基本输入输出。
- 高级功能的延迟、缓存、功耗和热管理代价。

了解即可：

- Kalman filter、RANSAC、光流、块匹配细节。
- 正则化超分、deconvolution、blind deblur 数学。
- HDR+、HDRNet、SID、Deep Burst SR 等论文路线。
- 语义 ISP、分层调参和 AI-ISP 协同。

后面再回看：

- 多帧 RAW burst pipeline 和端侧部署。
- IMU-camera calibration、rolling shutter-aware EIS。
- 神经渲染式散景和 depth-aware image processing。
- 任务驱动计算摄影和可信图像恢复。

### 19. 读完本章的验收标准

合格的学习结果应该是：

- 口头解释：能讲清计算摄影如何利用多帧、多摄、运动、深度和语义超越单帧 ISP。
- 输入输出：能写出 EIS、SR、夜景、散景、景深扩展、去模糊各自的输入、处理和输出。
- 公式理解：能解释多帧平均噪声标准差为什么约按 `1/sqrt(N)` 下降。
- 现象排查：能根据鬼影、重影、假细节、边缘假散景、视频闪烁提出原因。
- 工程判断：能说明高级功能在画质、延迟、缓存、功耗、热和可信度上的取舍。

## 15.1 视频稳定（EIS）：运动估计与补偿


### 15.1.1 EIS系统架构


电子图像稳定（Electronic Image Stabilization）是现代ISP的核心功能之一，特别在车载和移动机器人场景中至关重要。EIS系统主要包含三个关键模块：


```
输入帧序列 → 运动估计 → 运动滤波 → 运动补偿 → 稳定输出
     ↓            ↓           ↓           ↓
   陀螺仪     全局运动    轨迹平滑    图像变换
   数据       参数提取    与优化      与裁剪
```


### 15.1.2 运动估计算法


运动估计是EIS的核心，通常采用分层运动模型：


\[\begin{bmatrix} x' \\ y' \\ 1 \end{bmatrix} = \begin{bmatrix} a &amp; b &amp; t_x \\ c &amp; d &amp; t_y \\ 0 &amp; 0 &amp; 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix}\]


其中仿射变换参数通过特征点匹配或光流场估计获得。对于实时处理，硬件实现通常采用基于块匹配的运动估计：


1. **粗粒度全局运动估计**：将图像划分为16×16或32×32的宏块，计算块间的运动矢量
2. **精细化运动参数拟合**：使用RANSAC算法剔除局部运动outlier，拟合全局运动模型
3. **亚像素精度优化**：通过插值实现1/4或1/8像素精度的运动估计


### 15.1.3 运动滤波与轨迹平滑


原始运动轨迹需要经过滤波处理以区分有意运动和抖动：


\[\mathbf{p}_{smooth}(t) = \sum_{i=-N}^{N} w_i \cdot \mathbf{p}_{raw}(t+i)\]


其中权重$w_i$根据运动特性自适应调整。常用的滤波器包括：


- **卡尔曼滤波器**：适用于线性运动模型，计算复杂度低
- **粒子滤波器**：处理非线性运动，精度高但计算量大
- **低通滤波器**：简单高效，适合硬件实现


### 15.1.4 运动补偿与边界处理


运动补偿通过图像变换实现稳定输出：


1. **变换矩阵计算**：根据滤波后的运动参数计算逆变换矩阵
2. **图像重采样**：使用双线性或双三次插值进行像素重映射
3. **边界填充策略**： 过采样裁剪：预留10-20%的边界用于补偿
4. 边界外推：使用邻近像素或镜像填充
5. 自适应缩放：动态调整输出分辨率


### 15.1.5 硬件加速架构


EIS硬件加速器典型架构：


```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│  运动估计   │───→│  轨迹滤波器  │───→│ 变换引擎    │
│  (ME Unit)  │    │  (Kalman)    │    │ (Warp Unit) │
└─────────────┘    └──────────────┘    └─────────────┘
      ↑                   ↑                    ↓
┌─────────────┐    ┌──────────────┐    ┌─────────────┐
│ 特征提取器  │    │  IMU接口     │    │ 输出缓冲    │
└─────────────┘    └──────────────┘    └─────────────┘
```


关键设计考虑：


- **流水线深度**：平衡延迟与吞吐量，典型3-5级流水线
- **内存带宽**：运动估计需要参考帧访问，带宽需求约2-3倍输入数据率
- **精度权衡**：定点化运动参数，保留足够精度（通常16-bit定点）


## 15.2 超分辨率：多帧融合与上采样


### 15.2.1 超分辨率原理


超分辨率（Super-Resolution）通过融合多帧信息或学习先验知识提升图像分辨率：


\[\mathbf{y} = \mathbf{DBM}\mathbf{x} + \mathbf{n}\]


其中$\mathbf{y}$是低分辨率观测，$\mathbf{x}$是高分辨率图像，$\mathbf{D}$是下采样算子，$\mathbf{B}$是模糊核，$\mathbf{M}$是运动变换，$\mathbf{n}$是噪声。


### 15.2.2 多帧超分辨率算法


多帧SR利用亚像素位移信息重建高分辨率图像：


1. **亚像素配准**：精确估计帧间亚像素位移 \(\Delta\mathbf{p} = \arg\min_{\mathbf{p}} \sum_{i,j} |I_1(i,j) - I_2(i+p_x, j+p_y)|^2\)
2. **像素融合**：根据运动信息将多帧投影到高分辨率网格 \(HR(m,n) = \sum_{k} w_k \cdot LR_k(\mathbf{M}_k^{-1}(m,n))\)
3. **正则化重建**：解决病态逆问题 \(\hat{\mathbf{x}} = \arg\min_{\mathbf{x}} \|\mathbf{y} - \mathbf{Hx}\|^2 + \lambda\|\mathbf{Lx}\|^2\)


### 15.2.3 单帧超分辨率技术


基于插值和边缘导向的单帧SR：


1. **边缘导向插值**： 检测边缘方向
2. 沿边缘方向进行插值
3. 保持边缘锐利度
4. **基于样例的方法**： 构建高低分辨率图像块字典
5. 稀疏编码匹配
6. 高分辨率块重建


### 15.2.4 硬件实现策略


超分辨率硬件加速器设计：


```
多帧输入 → 运动估计 → 亚像素配准 → 像素融合 → 后处理
    ↓         ↓           ↓          ↓         ↓
帧缓存    光流计算    插值引擎    累加器   锐化滤波
```


关键优化：


- **内存访问模式**：块状访问减少DRAM带宽
- **定点化策略**：16-bit定点满足大部分场景
- **流水线设计**：重叠运动估计与像素融合

## 15.3 景深扩展：焦点堆叠与全焦图像


### 15.3.1 景深扩展原理


景深扩展（Extended Depth of Field）通过融合不同焦距的图像序列生成全焦图像：


\[DOF = \frac{2Nc \cdot f^2}{f^2 - N^2c^2}\]


其中$N$是光圈值，$c$是弥散圆直径，$f$是焦距。


### 15.3.2 焦点堆叠算法

1. **对焦测度计算**：评估每个像素的清晰度 \(FM(x,y) = \sum_{i,j \in W} |\nabla I(x+i, y+j)|^2\)

3. **多尺度融合**：避免边界伪影 \(I_{fused} = \sum_k w_k(x,y) \cdot I_k(x,y)\) 其中权重$w_k$基于高斯金字塔分解

## 15.4 计算散景：深度估计与渲染


### 15.4.1 散景效果原理


散景（Bokeh）是光学系统的点扩散函数（PSF）在离焦区域的表现。计算散景通过深度估计和选择性模糊模拟大光圈效果：


\[I_{bokeh}(x,y) = \sum_{(u,v) \in K} w(u,v,d(x,y)) \cdot I(x+u, y+v)\]


其中$K$是模糊核，$w$是基于深度$d$的权重函数。


### 15.4.2 深度估计技术


单目深度估计方法：


1. **基于散焦的深度估计（DFD）**： \(d = \frac{f^2}{N \cdot c \cdot |\sigma_1 - \sigma_2|}\) 其中$\sigma_1, \sigma_2$是两个不同焦距下的模糊程度
2. **基于相位的深度估计（PDAF）**： \(d = \frac{B \cdot f}{p}\) 其中$B$是基线，$p$是相位差
3. **基于机器学习的深度估计**： 使用预训练网络推断深度图
4. 边缘引导的深度传播
5. 多尺度特征融合


### 15.4.3 散景渲染算法


高质量散景渲染的关键技术：


1. **分层渲染**：根据深度将场景分层

```
前景层 → 模糊处理 →
                   → 深度混合 → 输出
焦点层 → 保持清晰 →
                   → 深度混合 → 输出
背景层 → 模糊处理 →
```


2. **光圈形状模拟**： 圆形光圈：高斯或圆盘模糊核
3. 多边形光圈：根据叶片数生成核
4. 猫眼效果：边缘渐变权重
5. **高光处理**： \(L_{highlight} = \max(0, L - threshold)^{\gamma}\) 增强亮部的散景光斑效果


### 15.4.4 边缘保持与过渡


避免前景边缘的光晕效应：


1. **双边滤波散景**： \(w(i,j) = \exp\left(-\frac{\|p_i-p_j\|^2}{2\sigma_s^2}\right) \cdot \exp\left(-\frac{|d_i-d_j|^2}{2\sigma_d^2}\right)\)
2. **分离式处理**： 前景与背景分别处理
3. 使用alpha混合避免硬边界
4. 深度不连续处的特殊处理
5. **迭代优化**： \(I^{(k+1)} = (1-\alpha)I^{(k)} + \alpha \cdot Blur(I^{(k)}, d)\)

计算散景的硬件架构：


```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  深度估计    │──→│  深度优化    │──→│  分层处理    │
│  (Depth)     │   │  (Refine)    │   │  (Layer)     │
└──────────────┘   └──────────────┘   └──────────────┘
       ↓                  ↓                   ↓
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  PDAF处理    │   │  引导滤波    │   │  模糊引擎    │
└──────────────┘   └──────────────┘   └──────────────┘
                                              ↓
                                       ┌──────────────┐
                                       │  混合单元    │
                                       └──────────────┘
```


优化策略：


- **可分离滤波**：将2D卷积分解为两个1D操作
- **查找表加速**：预计算不同深度的模糊核
- **块状处理**：减少内存访问，提高缓存命中率


## 15.5 夜景模式：多帧降噪与细节增强


### 15.5.1 夜景成像挑战


低照度环境的主要问题：


- **信噪比低**：光子噪声主导，SNR ∝ √(光子数)
- **动态范围大**：高光与暗部差异极大
- **色彩失真**：低照度下色彩响应非线性
- **运动模糊**：长曝光导致的抖动


### 15.5.2 多帧时域降噪


夜景模式的核心是多帧融合降噪：


1. **帧间配准**： \(\mathbf{T}_i = \arg\min_T \sum_{x,y} \rho(I_0(x,y) - I_i(T(x,y)))\) 使用鲁棒损失函数$\rho$处理outlier
2. **运动检测与分割**： \(M(x,y) = \begin{cases} 1, & |I_0(x,y) - I_i^{aligned}(x,y)| > \tau \\ 0, & otherwise \end{cases}\)
3. **自适应融合**： \(I_{fused} = \frac{\sum_i w_i \cdot (1-M_i) \cdot I_i^{aligned}}{\sum_i w_i \cdot (1-M_i)}\) 权重$w_i$基于噪声模型和配准质量


### 15.5.3 噪声模型与估计


准确的噪声建模对夜景降噪至关重要：


1. **泊松-高斯噪声模型**： \(\sigma^2(I) = \alpha \cdot I + \beta\) 其中$\alpha$是光子噪声系数，$\beta$是读出噪声
2. **噪声参数估计**： 基于图像块的方差分析
3. ISO依赖的查找表
4. 实时噪声水平估计
5. **空间变化噪声**： 考虑lens shading和温度梯度的影响


### 15.5.4 细节增强技术


在降噪的同时保持和增强细节：


1. **频域分离处理**：

```
输入 → 多尺度分解 → 低频：强降噪
                 → 中频：选择性增强  → 重构
                 → 高频：噪声抑制
```


2. **局部对比度增强**： \(I_{enhanced} = I + \lambda \cdot (I - I_{smooth})\) 其中$I_{smooth}$是引导滤波结果
3. **结构保持锐化**： \(S(x,y) = I(x,y) + k \cdot sign(\nabla I) \cdot |\nabla I|^{\gamma}\)


### 15.5.5 硬件实现架构


夜景模式的硬件加速器：


```
┌────────────┐  ┌────────────┐  ┌────────────┐  ┌────────────┐
│ 帧缓冲管理 │→│ 运动估计   │→│ 运动补偿   │→│ 时域融合   │
└────────────┘  └────────────┘  └────────────┘  └────────────┘
                      ↓              ↓               ↓
                ┌────────────┐  ┌────────────┐  ┌────────────┐
                │ 噪声估计   │  │ 运动掩码   │  │ 权重计算   │
                └────────────┘  └────────────┘  └────────────┘
                                                      ↓
┌────────────┐  ┌────────────┐  ┌────────────┐  ┌────────────┐
│ 空域降噪   │←│ 细节增强   │←│ 色彩校正   │←│ 融合输出   │
└────────────┘  └────────────┘  └────────────┘  └────────────┘
```


关键设计点：


- **多帧缓存**：典型需要3-8帧，使用DDR或片上SRAM
- **精度控制**：16-bit处理保持暗部细节
- **流水线平衡**：运动估计通常是瓶颈，需要优化


## 15.6 运动模糊消除与防抖算法


### 15.6.1 运动模糊形成机理


运动模糊的数学模型：


\[g(x,y) = \int_0^T h(x,y;t) \cdot f(x-v_x(t), y-v_y(t)) dt + n(x,y)\]


其中$g$是模糊图像，$f$是清晰图像，$h$是时变PSF，$v_x, v_y$是运动轨迹。


### 15.6.2 模糊核估计


准确估计模糊核是去模糊的关键：


1. **基于边缘的估计**： \(k = \arg\min_k \|\nabla g - k * \nabla f_{est}\|^2 + \lambda R(k)\)
2. **基于IMU的估计**： 将陀螺仪数据转换为模糊核： \(k(x,y) = \frac{1}{T} \sum_{t} \delta(x - \int_0^t \omega_x(\tau)d\tau, y - \int_0^t \omega_y(\tau)d\tau)\)
3. **盲去卷积**： 交替优化图像和模糊核： \(\{f^*, k^*\} = \arg\min_{f,k} \|g - k * f\|^2 + \lambda_f R_f(f) + \lambda_k R_k(k)\)


### 15.6.3 非均匀去模糊


处理空间变化的运动模糊：


1. **分块处理**： 将图像分割为重叠块
2. 每块独立估计模糊核
3. 融合去模糊结果
4. **光流引导**： \(f(x,y) = \arg\min_f \|g(x,y) - \int k(x,y,u,v) f(u,v) dudv\|^2\)
5. **深度感知去模糊**： 根据深度图调整局部模糊核


### 15.6.4 防抖算法设计


预防性防抖策略：


1. **快门速度优化**： \(t_{max} = \frac{1}{f \cdot \tan(\theta_{max})}\) 其中$\theta_{max}$是可接受的最大抖动角
2. **ISO自适应调节**： 平衡噪声与运动模糊： \(ISO_{opt} = \arg\min_{ISO} (w_n \cdot Noise(ISO) + w_m \cdot Blur(1/t(ISO)))\)
3. **多帧合成防抖**： 短曝光捕获多帧
4. 运动补偿对齐
5. 噪声感知融合


### 15.6.5 硬件加速实现


运动去模糊硬件架构：


```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  IMU接口     │──→│  模糊核估计  │──→│  FFT引擎     │
└──────────────┘   └──────────────┘   └──────────────┘
       ↓                  ↓                   ↓
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  运动轨迹    │   │  正则化处理  │   │  频域去卷积  │
└──────────────┘   └──────────────┘   └──────────────┘
                                              ↓
                                       ┌──────────────┐
                                       │  IFFT & 输出 │
                                       └──────────────┘
```


优化要点：


- **FFT加速**：使用专用FFT硬件单元
- **迭代优化**：Richardson-Lucy算法的硬件实现
- **边界处理**：循环边界或镜像扩展


## 本章小结


本章系统介绍了计算摄影技术在现代ISP中的实现，涵盖了六大高级功能模块：


1. **视频稳定（EIS）**：通过运动估计、轨迹滤波和运动补偿实现稳定输出，关键在于准确的全局运动模型和实时性保证

5. **夜景模式**：多帧融合降噪与细节增强，需要精确的噪声建模和运动处理
6. **运动去模糊**：通过模糊核估计和反卷积恢复清晰图像，关键是准确的PSF估计


### 关键技术要点


- **多帧处理框架**：运动估计、配准、融合是多个功能的共同基础
- **深度信息利用**：深度图在散景、去模糊等功能中起关键作用
- **硬件加速设计**：FFT、卷积、滤波等计算密集型操作需要专用硬件
- **精度与性能权衡**：定点化、流水线深度、内存带宽的优化策略
- **鲁棒性设计**：处理运动物体、遮挡、光照变化等挑战

**练习15.1**：EIS运动模型选择
给定一个车载场景，相机固定在车顶，主要运动包括车身颠簸和转弯。请分析应该选择何种运动模型（平移、仿射、投影）？并说明原因。


*提示（Hint）*：考虑不同运动模型的自由度和车载场景的运动特性。


<details>
<summary>答案</summary>

应选择仿射变换模型。原因：
1. 平移模型（2自由度）过于简单，无法处理旋转
2. 投影变换（8自由度）过于复杂，增加计算负担
3. 仿射变换（6自由度）刚好可以处理：
   - 平移（车身前后左右移动）
   - 旋转（转弯时的偏航）
   - 缩放（轻微的前后移动）
   - 剪切（车身倾斜）

车载场景不涉及强透视变化，仿射模型足够且效率高。
</details>


**练习15.2**：超分辨率放大倍数计算
已知原始图像分辨率1920×1080，通过4帧亚像素位移图像进行超分辨率重建。如果帧间位移分别为(0,0)、(0.5,0)、(0,0.5)、(0.5,0.5)像素，理论上最大可以达到多少分辨率？


*提示（Hint）*：考虑亚像素位移如何增加采样密度。


<details>
<summary>答案</summary>

理论上可以达到3840×2160（4K分辨率），即2倍放大。

分析：
- 4帧位移构成了2×2的亚像素采样网格
- 每个原始像素位置获得4个采样点
- 水平和垂直方向各增加1倍采样密度
- 最终分辨率：1920×2 = 3840, 1080×2 = 2160

注意：实际效果受噪声、配准精度等因素影响。
</details>


**练习15.3**：景深计算
相机参数：焦距f=50mm，光圈N=2.8，弥散圆直径c=0.03mm。计算对焦距离为2m时的景深范围。


*提示（Hint）*：使用景深公式，分别计算前景深和后景深。


<details>
<summary>答案</summary>

景深计算：
- 超焦距：$H = \frac{f^2}{N \cdot c} = \frac{50^2}{2.8 \times 0.03} = 29.76m$
- 前景深：$DOF_{near} = \frac{s \cdot (H-f)}{H+s-2f} = \frac{2000 \times (29760-50)}{29760+2000-100} = 1.87m$
- 后景深：$DOF_{far} = \frac{s \cdot (H-f)}{H-s} = \frac{2000 \times (29760-50)}{29760-2000} = 2.14m$
- 总景深：2.14 - 1.87 = 0.27m

景深范围：1.87m 到 2.14m
</details>


**练习15.4**：噪声水平估计
夜景模式下，测得某区域在不同亮度下的噪声方差：


- 亮度100：方差25
- 亮度200：方差35
- 亮度400：方差55


根据泊松-高斯模型$\sigma^2 = \alpha I + \beta$，计算参数$\alpha$和$\beta$。


*提示（Hint）*：使用最小二乘法拟合。


<details>
<summary>答案</summary>

设置方程组：
- $25 = 100\alpha + \beta$ ... (1)
- $35 = 200\alpha + \beta$ ... (2)
- $55 = 400\alpha + \beta$ ... (3)

从(2)-(1)：$10 = 100\alpha$，得$\alpha = 0.1$
从(3)-(2)：$20 = 200\alpha$，得$\alpha = 0.1$（验证）

代入(1)：$\beta = 25 - 100 \times 0.1 = 15$

结果：$\alpha = 0.1$（光子噪声系数），$\beta = 15$（读出噪声）
</details>

**练习15.5**：EIS与OIS协同设计
某手机同时配备OIS（光学防抖）和EIS。OIS可补偿±2°抖动，响应频率10-100Hz；EIS可补偿±5°，但有10%裁剪损失。设计一个协同策略，优化整体防抖效果。


*提示（Hint）*：考虑频率分离和各自优势。


<details>
<summary>答案</summary>

协同策略设计：

1. **频率分离方案**：
   - OIS处理高频抖动（&gt;10Hz）：快速响应，无画质损失
   - EIS处理低频运动（&lt;10Hz）：大幅度补偿能力

2. **分工策略**：
   - 小幅度抖动（&lt;2°）：优先OIS，保持全画幅
   - 大幅度抖动（2-5°）：OIS补偿2°，EIS补偿剩余
   - 超大幅度（&gt;5°）：EIS全力补偿，接受裁剪

3. **实现流程**：
   ```
   IMU数据 → 频率分解 → 高频：OIS控制信号
                    → 低频：EIS补偿参数
   残余运动 → EIS二次补偿
   ```

4. **优化要点**：
   - 预测算法减少OIS/EIS切换延迟
   - 自适应裁剪：根据场景动态调整
   - 功耗管理：静止时关闭OIS节能

**练习15.6**：多帧超分辨率的运动估计精度要求
要实现2倍超分辨率，需要4帧图像。如果要求最终PSNR达到35dB以上，运动估计的精度应该达到多少亚像素？考虑实际噪声σ=5的影响。


*提示（Hint）*：配准误差会直接影响重建质量，建立误差传播模型。


<details>
<summary>答案</summary>

精度要求分析：

1. **误差传播模型**：
   配准误差$\epsilon$导致的重建误差：
   $MSE_{reg} \approx \epsilon^2 \cdot |\nabla I|^2$

2. **PSNR要求**：
   PSNR = 35dB → MSE &lt; 31.6
   考虑噪声：$MSE_{total} = MSE_{reg} + \sigma^2 = MSE_{reg} + 25$
   因此：$MSE_{reg} &lt; 6.6$

3. **梯度估计**：
   自然图像平均梯度：$|\nabla I| \approx 20$（8-bit图像）

4. **精度计算**：
   $\epsilon^2 \cdot 400 &lt; 6.6$
   $\epsilon &lt; 0.128$ 像素

5. **结论**：
   需要1/8像素精度的运动估计
   实际实现可用1/8像素插值或光流算法

额外考虑：
- 多帧累积可部分抵消随机误差
- 边缘区域需要更高精度
- 可采用迭代优化提升精度
</details>


**练习15.7**：计算散景的深度图精度需求
要实现自然的散景效果，模糊核直径需要在0-20像素范围内连续变化。已知镜头参数：f=85mm，N=1.4，像素尺寸5μm。计算所需的深度图量化位数。


*提示（Hint）*：建立深度与模糊核大小的关系。


<details>
<summary>答案</summary>

深度精度分析：

1. **模糊圆直径公式**：
   $CoC = \frac{f \cdot m \cdot |s - s_0|}{N \cdot s \cdot (s_0 - f)}$
   其中m是放大率，s是物距，s₀是对焦距离

2. **像素单位转换**：
   20像素 = 20 × 5μm = 100μm = 0.1mm

3. **深度范围计算**：
   设对焦2m，最大模糊对应：
   - 前景：0.5m（人像常见最近距离）
   - 背景：∞（无穷远）

4. **深度采样**：
   深度范围：0.5m到∞
   使用对数采样：$d_i = d_{min} \cdot r^i$

5. **量化级数**：
   要求相邻深度的CoC差异&lt; 1像素
   计算得需要约100个深度级

6. **位数要求**：
   $2^n &gt; 100$ → n = 7位

7. **实际建议**：
   使用8位深度图（256级）
   - 提供更平滑的过渡
   - 便于硬件实现（字节对齐）
   - 可处理更复杂场景
</details>


**练习15.8**：夜景模式的最优帧数选择
夜景场景，ISO 3200时读出噪声σ_r=10，光子噪声系数α=0.2。拍摄静态场景，平均亮度I=50。如果要将信噪比提升到30dB，需要融合多少帧？考虑帧间配准误差为0.2像素。


*提示（Hint）*：多帧融合的噪声减少与帧数的关系。


<details>
<summary>答案</summary>

最优帧数计算：

1. **初始噪声水平**：
   $\sigma^2 = \alpha I + \sigma_r^2 = 0.2 \times 50 + 100 = 110$
   初始SNR = $10\log_{10}(\frac{50^2}{110}) = 13.6dB$

2. **目标噪声水平**：
   SNR = 30dB → $\sigma_{target}^2 = \frac{50^2}{10^3} = 2.5$

3. **理想融合**（无配准误差）：
   N帧融合：$\sigma_{fused}^2 = \frac{\sigma^2}{N} = \frac{110}{N}$
   需要：$\frac{110}{N} &lt; 2.5$ → N &gt; 44帧

4. **考虑配准误差**：
   配准误差贡献：$\sigma_{reg}^2 = \epsilon^2 \cdot |\nabla I|^2 \cdot N$
   假设$|\nabla I| = 10$：$\sigma_{reg}^2 = 0.04 \times 100 \times N = 4N$

5. **总噪声**：
   $\sigma_{total}^2 = \frac{110}{N} + 4N$

6. **优化**：
   $\frac{d\sigma_{total}^2}{dN} = -\frac{110}{N^2} + 4 = 0$
   $N_{opt} = \sqrt{\frac{110}{4}} = 5.2 \approx 5$帧

7. **验证**：
   5帧时：$\sigma_{total}^2 = 22 + 20 = 42$
   SNR = $10\log_{10}(\frac{2500}{42}) = 17.7dB$

8. **结论**：
   - 配准误差限制了有效帧数
   - 建议使用5-8帧
   - 需要改进配准精度或使用鲁棒融合算法达到30dB目标
</details>


## 常见陷阱与错误（Gotchas）


### 1. EIS实现陷阱


**错误**：直接使用所有特征点计算全局运动


- **问题**：前景运动物体污染全局运动估计
- **解决**：使用RANSAC或加权最小二乘剔除outlier


**错误**：固定大小的稳定裁剪边界


- **问题**：轻微抖动时浪费分辨率，剧烈抖动时边界不足
- **解决**：自适应裁剪，根据运动幅度动态调整


### 2. 超分辨率陷阱


**错误**：忽略亚像素配准精度


- **问题**：配准误差导致模糊而非锐化
- **解决**：至少1/4像素精度，关键区域使用光流


**错误**：对运动区域强行超分


- **问题**：产生鬼影和伪影
- **解决**：运动检测+ 自适应处理


### 3. 景深扩展陷阱


**错误**：使用单一对焦测度


- **问题**：不同纹理区域表现差异大
- **解决**：多测度融合 + 场景自适应


**错误**：决策图的硬切换


- **问题**：可见的拼接边界
- **解决**：多尺度融合或引导滤波平滑


### 4. 计算散景陷阱


**错误**：均匀模糊整个背景


- **问题**：不真实，缺乏深度层次
- **解决**：基于精确深度图的渐进模糊


**错误**：前景边缘的色差扩散


- **问题**：前景轮廓出现彩色边缘
- **解决**：边缘感知滤波 + 色彩抑制


### 5. 夜景模式陷阱


**错误**：过度依赖长曝光


- **问题**：运动模糊无法恢复
- **解决**：多短曝光帧融合


**错误**：固定的降噪强度


- **问题**：亮部过度平滑，暗部噪声残留
- **解决**：局部自适应降噪


### 6. 运动去模糊陷阱


**错误**：使用单一全局模糊核


- **问题**：忽略深度变化和旋转运动
- **解决**：分块处理或非均匀去模糊


**错误**：过度锐化补偿


- **问题**：振铃效应和噪声放大
- **解决**：正则化约束 + 迭代优化
