# 第9章：NLM算法硬件实现专题



### 1. 本章先解决什么问题

第 8 章已经讲了 ISP 降噪全景：均值、高斯、双边、导向、NLM、BM3D、时域降噪、学习型降噪等。第 9 章把焦点收窄到 Non-Local Means，简称 NLM，并且重点看它为什么“效果好但硬件难”。

NLM 的核心直觉是：不要只看当前像素附近的一小圈，也不要只比较单个像素值，而是在更大范围里找“长得像”的小图块 patch。相似 patch 里的中心像素，很可能代表同一类真实结构；把它们按相似程度加权平均，就能降低随机噪声，同时比普通均值滤波更能保留纹理。

本章最小链路是：

```text
输入：一张带噪图像，通常是灰度、RAW 同色平面、RGB/Y 通道或局部 crop
处理：为每个像素取参考 patch，在搜索窗口内找候选 patch，计算相似度，生成权重，加权平均
输出：噪声降低但边缘和纹理尽量保留的图像
```

如果放到硬件实现里，链路会更具体：

```text
像素流/图像缓存 -> patch/window 缓存 -> 块距离计算 -> 权重近似 -> 归一化 -> 加权累加 -> 输出
```

读完本章，至少要能回答：

- NLM 为什么叫 non-local。
- patch 相似度为什么比单像素相似度更稳定。
- `h`、patch 大小、搜索窗口大小分别控制什么。
- 为什么 NLM 的计算量和访存量非常大。
- 硬件实现通常会做哪些近似。

### 2. 从“局部平均”走到“非局部相似”

普通均值滤波只看局部窗口，例如 3x3 或 5x5。它默认邻近像素应该相似，所以可以平均。但真实图像中，邻近像素不一定属于同一个结构：边缘两侧可能是不同物体，纹理区域也可能快速变化。

双边滤波比均值滤波聪明一些：它不只看距离，还看像素值是否相近。但它仍主要围绕局部邻域。

NLM 的想法更进一步：

```text
如果远处有一块纹理和当前小块很像，它也可以帮助当前像素降噪。
相似性不一定只发生在空间邻近处，而可能出现在图像中很多地方。
```

例如一张砖墙照片里，同样的砖块纹理会反复出现；一张织物照片里，相似纹理也会重复。NLM 利用这种自然图像自相似性，把多个相似 patch 的信息合起来。

这也是 NLM 与普通滤波最根本的区别：

| 方法 | 看什么 | 相似性依据 | 优点 | 风险 |
|---|---|---|---|---|
| 均值滤波 | 局部邻域 | 空间距离近 | 简单快 | 边缘糊 |
| 高斯滤波 | 局部邻域 | 空间距离近且中心权重大 | 平滑自然 | 纹理损失 |
| 双边滤波 | 局部邻域 | 距离近 + 像素值相近 | 边缘保持 | 参数敏感 |
| NLM | 搜索窗口内 patch | 小块整体相似 | 纹理保留更好 | 计算和访存重 |
| BM3D | 非局部相似 patch 组 | patch 分组 + 变换域稀疏 | 传统强基线 | 更复杂 |

### 3. NLM 公式先用人话理解

NLM 常见公式是：

```text
u_hat(i) = sum_j w(i, j) * v(j)
```

变量解释：

- `i`：当前要降噪的目标像素位置。
- `j`：搜索窗口里的候选像素位置。
- `v(j)`：带噪图像中候选位置的像素值。
- `w(i, j)`：候选位置 `j` 对目标位置 `i` 的权重。
- `u_hat(i)`：目标像素降噪后的估计值。

权重通常由 patch 距离决定：

```text
w(i, j) = exp(- distance(patch_i, patch_j) / h^2) / Z(i)
```

其中：

- `patch_i`：以 `i` 为中心的小图块，例如 3x3、5x5、7x7。
- `patch_j`：以 `j` 为中心的小图块。
- `distance`：两个 patch 的差异，常用 SSD，也就是逐像素差值平方和。
- `h`：滤波强度参数。
- `Z(i)`：归一化项，保证所有权重加起来为 1。

一句话：

```text
patch 越像，distance 越小，权重越大。
patch 越不像，distance 越大，权重越小。
h 越大，不像的 patch 也能拿到较大权重，降噪更强但更容易糊。
h 越小，只相信非常相似的 patch，细节保留更好但降噪可能不足。
```

### 4. 一个小数值例子

假设当前 patch 是一个 1D 简化版本：

```text
patch_i = [100, 104, 102]
```

搜索窗口里有三个候选 patch：

```text
patch_a = [101, 103, 102]
patch_b = [180, 185, 181]
patch_c = [96, 107, 101]
```

计算 SSD：

```text
distance(i, a) = (100-101)^2 + (104-103)^2 + (102-102)^2 = 2
distance(i, b) = (100-180)^2 + (104-185)^2 + (102-181)^2 = 19202
distance(i, c) = (100-96)^2 + (104-107)^2 + (102-101)^2 = 26
```

如果 `h = 10`，则 `h^2 = 100`：

```text
raw_weight_a = exp(-2/100)    ≈ 0.980
raw_weight_b = exp(-19202/100)≈ 接近 0
raw_weight_c = exp(-26/100)   ≈ 0.771
```

归一化后，`a` 和 `c` 会贡献主要权重，`b` 基本不会参与。这正是 NLM 的核心：不是所有邻居都平均，而是让“像我”的 patch 更有发言权。

如果把 `h` 改成很大，比如 `h = 100`，`patch_b` 也可能获得非零权重，降噪会更强，但也更容易把不相似结构混进来。

### 5. patch 大小、搜索窗口和 h 分别控制什么

NLM 有三个初学者必须抓住的参数。

| 参数 | 控制什么 | 太小会怎样 | 太大会怎样 |
|---|---|---|---|
| patch size | 比较相似性时看的小块大小 | 相似判断不稳，容易受噪声影响 | 细节变化被平均，计算量增加 |
| search window | 去哪里找相似 patch | 找不到足够相似块，降噪弱 | 计算和访存暴涨，可能引入错误匹配 |
| h | 权重衰减速度/滤波强度 | 只信极少数 patch，噪声残留 | 不相似 patch 也被混入，细节变糊 |

一个常见起步配置是：

```text
patch size：3x3 或 5x5
search window：11x11、15x15、21x21
h：和噪声标准差相关，通常需要随噪声水平调节
```

但这些不是固定真理。噪声越强，patch 距离本身越不可靠；纹理越复杂，错误匹配越容易；硬件越受限，搜索窗口和 patch size 越要保守。

### 6. 为什么 NLM 计算量吓人

假设图像大小是 `W x H`，每个像素都要处理。对每个像素：

- 搜索窗口大小是 `S x S`。
- patch 大小是 `P x P`。
- 每个候选 patch 要做 `P^2` 次差值、平方、加和。
- 每个候选位置还要算权重、累加、归一化。

粗略复杂度：

```text
每像素计算量 ≈ S^2 * P^2
整图计算量 ≈ W * H * S^2 * P^2
```

举例：

```text
图像：1920 x 1080 ≈ 2,073,600 像素
搜索窗口：21 x 21 = 441
patch：7 x 7 = 49

每像素 patch 差异项 ≈ 441 * 49 = 21,609
整帧差异项 ≈ 2,073,600 * 21,609 ≈ 44,800,000,000
```

这还没算指数函数、归一化、内存读取和边界处理。对实时 ISP 来说，这个量级非常沉重。若是 4K 60fps，更不能按朴素版本直接做。

所以本章标题里“硬件实现专题”的重点不是把数学公式搬进 RTL，而是理解：NLM 的哪些步骤最贵，哪些近似最常见，哪些质量损失可以接受。

### 7. 硬件实现的四个大难点

难点 1：访存量大。

NLM 需要反复读取重叠 patch。软件里可以随机访问内存；硬件 ISP 通常是流式像素输入，不能随便回看整张图。必须设计 line buffer、window buffer、patch buffer 和数据复用。

难点 2：块距离计算多。

每个候选 patch 都要计算 SSD：

```text
SSD = sum((patch_i[k] - patch_j[k])^2)
```

这意味着大量减法、平方、累加。平方可以用乘法器、查表或近似绝对值替代，但无论怎样都要消耗资源。

难点 3：指数权重贵。

标准 NLM 用：

```text
exp(-SSD / h^2)
```

指数函数不适合直接硬件逐像素计算。常见做法是 LUT、分段线性近似、截断、小数定点近似，甚至改用更简单的权重函数。

难点 4：归一化需要除法。

最终输出通常是：

```text
output = sum(weight * value) / sum(weight)
```

除法也贵。硬件里常用倒数 LUT、定点 reciprocal、移位近似或限制权重格式来简化。

### 8. 硬件友好近似有哪些

为了让 NLM 能在硬件或实时系统里运行，常见近似包括：

| 近似方向 | 做法 | 好处 | 风险 |
|---|---|---|---|
| 限制搜索窗口 | 只在 7x7、11x11、15x15 内找 | 降低计算和缓存 | 找不到远处相似纹理 |
| 限制 patch 大小 | 用 3x3 或 5x5 | 降低 SSD 成本 | 相似判断更受噪声影响 |
| 预筛选 | 先比较均值/方差/中心像素 | 跳过明显不相似 patch | 可能错过有效 patch |
| 早停 | SSD 累加超过阈值就停止 | 减少无用计算 | 控制逻辑更复杂 |
| 权重 LUT | 用查表代替指数 | 快、可定点 | 精度受 LUT 大小影响 |
| 距离截断 | SSD 太大直接权重为 0 | 节省权重计算 | 阈值不当会残留噪声 |
| 低位宽定点 | 限制权重/累加位宽 | 节省面积和功耗 | 量化误差、溢出风险 |
| 分块处理 | 只对局部 tile 做 NLM | 缓存可控 | tile 边界可能不连续 |
| 多尺度 | 低分辨率找相似，高分辨率细化 | 降低搜索成本 | 细节匹配可能变差 |

这些近似不是偷懒，而是工程现实。好的硬件实现往往不是完全复现论文公式，而是在质量、吞吐、面积、功耗、延迟和验证难度之间找到平衡。

### 9. 和 RAW/ISP pipeline 的关系

NLM 可以用于灰度图、RGB 图、YUV 图，也可以用于 RAW 域。不同位置的假设不同。

RAW 域 NLM：

- 优点：噪声更接近传感器模型，demosaic 前就能抑制噪声。
- 难点：Bayer 每个像素只有一个颜色采样，patch 比较要注意 CFA 相位。
- 风险：跨颜色直接比较会破坏颜色结构。

Y/RGB 域 NLM：

- 优点：图像已经完整，patch 相似性更直观。
- 难点：噪声经过 demosaic、AWB、CCM、tone 后已不再简单。
- 风险：对纹理和颜色边缘过度平滑。

视频/时域扩展：

- 可以在相邻帧中寻找相似 patch。
- 降噪潜力更强。
- 但运动、遮挡、光照变化会带来错误匹配和鬼影。

因此，学习 NLM 时要先问：

```text
输入是什么域？
噪声模型是什么？
patch 比较是否需要同色/同相位？
输出会交给哪个后续模块？
硬件是否允许这个窗口和访存模式？
```

### 10. NLM、BM3D 和 VBM4D 的关系

NLM 和 BM3D 都利用非局部相似性，但 BM3D 更进一步。NLM 是找到相似 patch 后做加权平均；BM3D 会把相似 patch 堆成三维组，在 3D 变换域做稀疏化和协同滤波。

可以这样理解：

```text
NLM：相似 patch 加权平均。
BM3D：相似 patch 分组 -> 3D 变换 -> 阈值/维纳滤波 -> 聚合。
VBM4D：把 BM3D 的思想扩展到视频，多了时间维度。
```

Dabov 等人的 BM3D 是传统图像降噪强基线；Maggioni 等人的 VBM4D 是视频降噪重要方法。它们质量强，但硬件复杂度也高，尤其是块匹配、分组、变换、聚合、帧缓存和运动处理。

本章可以把 NLM 看成理解 BM3D/VBM4D 的入口：先掌握“相似 patch 搜索 + 权重/聚合”的基本思想，再看更复杂的变换域协同滤波。

### 11. 最小可验证实验

实验 1：参数对效果和耗时的影响。

1. 准备一张含有平坦区、纹理区、边缘区的灰度图或 Y 通道图。
2. 加入已知标准差的 Gaussian noise。
3. 固定 `h`，分别测试搜索窗口 7x7、11x11、21x21。
4. 固定搜索窗口，分别测试 patch 3x3、5x5、7x7。
5. 记录运行时间、PSNR/SSIM、局部 crop 主观质量。

实验 2：h 参数扫描。

1. 固定噪声水平和窗口大小。
2. 从小到大扫描 `h`。
3. 观察噪声残留、纹理损失、边缘变软。
4. 记录哪个 `h` 在平坦区和纹理区之间取舍最好。

实验 3：错误匹配观察。

1. 找一张重复纹理图，例如布料、砖墙、树叶。
2. 在一个纹理边界附近选目标 patch。
3. 可视化搜索窗口中权重最高的若干候选 patch。
4. 观察是否有不属于同一结构的 patch 被误认为相似。

实验 4：硬件近似模拟。

1. 标准 NLM 作为参考。
2. 把指数权重替换为 LUT 或分段线性近似。
3. 加入 SSD 截断和早停。
4. 把浮点改成定点模拟。
5. 对比质量下降和速度提升。

实验 5：RAW 同色约束。

1. 取 Bayer RAW 的某一个同色平面，例如只处理 G 或只处理 R。
2. 与直接把 Bayer 当普通灰度图做 NLM 对比。
3. 观察跨 CFA 相位比较是否引入颜色或纹理异常。

### 12. 错误现象排查表

| 现象 | 可能原因 | 排查方向 |
|---|---|---|
| 运行极慢 | 搜索窗口或 patch 太大，朴素实现重复计算 | 统计 `S^2 * P^2`，加入预筛选/缓存/近似 |
| 纹理被抹平 | `h` 太大或错误 patch 被混入 | 降低 `h`，检查权重最高 patch |
| 噪声残留明显 | `h` 太小、窗口太小、相似 patch 太少 | 增大 `h` 或搜索窗口 |
| 边缘附近有涂抹 | 跨边缘 patch 参与平均 | 加相似度阈值、边缘保护或结构预筛 |
| 细节出现奇怪重复纹理 | 远处错误相似 patch 权重大 | 限制搜索范围，检查 patch 特征 |
| 硬件结果偏暗/偏亮 | 权重归一化或定点缩放错误 | 检查 `sum(weight)`、除法近似和饱和 |
| 局部块边界明显 | tile 分块处理没有重叠或边界融合 | 增加 overlap，改进边界处理 |
| RAW 处理后有颜色异常 | CFA 相位被混用 | 按同色平面或同相位 patch 处理 |
| 高噪声下匹配失败 | 噪声污染 patch 距离 | 增大 patch、先粗降噪、使用噪声校正距离 |

### 13. 常见误区

- 误区 1：搜索窗口越大越好。窗口大能找到更多候选，但计算和错误匹配也会增加。
- 误区 2：patch 越大越好。patch 大更稳定，但会跨越结构边界，也会显著增加计算量。
- 误区 3：NLM 一定比双边滤波好。纹理重复明显时 NLM 有优势；实时低功耗场景可能双边/导向更合适。
- 误区 4：只要 PSNR 高就说明参数好。局部纹理涂抹、重复伪影和边缘软化需要 crop 检查。
- 误区 5：硬件实现就是把软件公式搬过去。指数、除法、随机访存和浮点权重都需要近似或重构。
- 误区 6：RAW 可以直接当普通灰度图做 NLM。Bayer 相位和颜色采样必须考虑。
- 误区 7：早停和阈值只影响速度。它们也会改变哪些 patch 参与平均，从而改变画质。

### 14. 学习优先级

必须掌握：

- NLM 的非局部自相似直觉。
- patch、search window、`h`、SSD、权重归一化的含义。
- 复杂度为什么是 `W*H*S^2*P^2` 量级。
- 硬件瓶颈：访存、SSD、指数、归一化、定点位宽。
- 参数变化对噪声残留和细节损失的影响。

了解即可：

- 高斯加权 patch 距离。
- 积分图、预筛选、早停、多尺度搜索等加速思路。
- BM3D/VBM4D 与 NLM 的关系。
- FPGA/ASIC 中 line buffer、BRAM、DSP、LUT 的资源权衡。

后面再回看：

- 快速 NLM 论文中的积分图/滑动距离复用。
- 完整 VLSI/FPGA 架构、吞吐建模、功耗分析。
- RAW burst denoise、video denoise 与学习型非局部注意力机制。

### 16. 读完本章的验收标准

合格的学习结果应该是：

- 口头解释：能讲清 NLM 如何利用相似 patch 降噪。
- 公式理解：能解释 `u_hat(i)=sum_j w(i,j)v(j)` 和权重公式里每个变量的含义。
- 参数判断：能说明 patch size、search window、`h` 对质量和复杂度的影响。
- 复杂度估算：能给定图像大小和参数，估算计算量为什么很大。
- 硬件意识：能指出访存、SSD、指数、归一化、定点化这些硬件瓶颈。

## 本章概述


Non-Local Means（NLM）算法作为图像降噪领域的里程碑技术，通过利用图像的自相似性实现了优异的降噪效果。本章深入探讨NLM算法从理论到硬件实现的完整技术链路，重点分析算法的硬件架构设计、优化策略以及在现代ISP中的集成方案。我们将详细剖析相似度计算、搜索策略优化、内存访问模式、定点化设计等关键技术点，并探讨BM3D等高级变种算法的硬件实现考虑。


## 9.1 Non-Local Means算法原理深度解析


### 9.1.1 算法理论基础


Non-Local Means（NLM）算法由Buades等人于2005年提出，其核心思想是利用图像的自相似性进行降噪。与传统的局部降噪方法不同，NLM通过在整幅图像中搜索相似的图像块来估计像素值，实现了更好的细节保持和噪声抑制平衡。


算法基于以下关键观察：


1. **自然图像的冗余性**：自然图像中存在大量重复或相似的纹理模式
2. **非局部相似性**：相似的图像块可能分布在图像的不同位置
3. **加权平均降噪**：通过对相似块进行加权平均可以有效抑制噪声


NLM算法的基本流程：


```
输入图像 → 块提取 → 相似度计算 → 权重生成 → 加权平均 → 输出图像
     ↑                    ↓
     └── 搜索窗口定义 ←──┘
```


### 9.1.2 数学模型与权重计算


NLM算法的数学表达式为：


\[\hat{u}(i) = \sum_{j \in \Omega_i} w(i,j) \cdot v(j)\]


其中：


- $\hat{u}(i)$ 是像素 $i$ 的降噪后估计值
- $v(j)$ 是噪声图像中像素 $j$ 的值
- $\Omega_i$ 是以像素 $i$ 为中心的搜索窗口
- $w(i,j)$ 是归一化权重，满足 $\sum_{j \in \Omega_i} w(i,j) = 1$


权重计算基于块间的相似度：


\[w(i,j) = \frac{1}{Z(i)} \exp\left(-\frac{\|N(v_i) - N(v_j)\|^2_{2,a}}{h^2}\right)\]


其中：


- $N(v_i)$ 表示以像素 $i$ 为中心的图像块
- $|\cdot|^2_{2,a}$ 是高斯加权的欧氏距离
- $h$ 是滤波参数，控制降噪强度
- $Z(i)$ 是归一化常数


高斯加权欧氏距离的计算：


\[\|N(v_i) - N(v_j)\|^2_{2,a} = \sum_{k \in B} G_a(k) \cdot |v(i+k) - v(j+k)|^2\]


其中 $G_a$ 是标准差为 $a$ 的高斯核，$B$ 是块的邻域。


### 9.1.3 算法复杂度分析


NLM算法的计算复杂度分析对硬件设计至关重要：


**时间复杂度**：


- 基础实现：$O(N^2 \cdot S^2 \cdot P^2)$ $N^2$：图像尺寸
- $S^2$：搜索窗口大小
- $P^2$：图像块大小


**空间复杂度**：


- 存储需求：$O(N^2 + S^2 \cdot P^2)$ 输入/输出图像缓存
- 搜索窗口缓存
- 权重表存储


**关键性能瓶颈**：


1. **计算密集**：每个像素需要 $S^2$ 次块匹配运算
2. **内存密集**：大量的数据读取和重用
3. **指数运算**：权重计算中的指数函数


硬件实现的优化目标：


- 减少冗余计算：利用块重叠特性
- 优化内存访问：设计高效的缓存策略
- 简化复杂运算：使用查找表替代指数运算

### 9.2.2 欧氏距离计算优化


欧氏距离计算是NLM算法的核心运算，其优化直接影响整体性能：


**基础计算流程**：


```
对于每个块对(i,j)：
1. 差值计算：diff[k] = patch_i[k] - patch_j[k]
2. 平方计算：sq[k] = diff[k]^2
3. 加权累加：dist = Σ(G[k] × sq[k])
```


**硬件优化技术**：


1. **并行处理架构**：

```
┌─────────┐  ┌─────────┐  ┌─────────┐
│ PE_0    │  │ PE_1    │  │ PE_2    │  并行处理单元
│ diff→sq │  │ diff→sq │  │ diff→sq │
└────┬────┘  └────┬────┘  └────┬────┘
     │            │            │
     └────────────┼────────────┘
                  ↓
           ┌──────────────┐
           │  加权累加树   │
           └──────────────┘
```


2. **平方运算简化**： 小位宽输入：使用查找表（LUT）
3. 近似计算：$(a+b)^2 \approx a^2 + 2ab + b^2$ 分解
4. 移位近似：对2的幂次使用移位操作
5. **高斯权重优化**： 预计算权重表，存储在ROM中
6. 利用高斯核的对称性减少存储
7. 使用简化核：如 [1,2,1]/4 替代精确高斯


### 9.2.3 权重归一化策略


权重归一化确保加权和为1，是保证算法稳定性的关键：


**归一化方法**：


1. **直接归一化**： \(w_{norm}(i,j) = \frac{w(i,j)}{\sum_{k \in \Omega} w(i,k)}\) 需要两遍扫描：计算权重和归一化
2. 硬件实现需要除法器
3. **近似归一化**： 使用移位替代除法：选择最接近的2的幂次
4. 迭代归一化：通过反馈调整权重和
5. **硬件实现架构**：

```
权重计算 → 累加器 → 倒数LUT → 乘法器阵列
   ↓          ↓         ↓           ↓
w[0..n]    Σw[i]     1/Σw    w_norm[0..n]
```


**定点化考虑**：


- 权重范围：[0, 1]，使用U0.16格式
- 累加器位宽：log2(搜索窗口大小) + 16位
- 防溢出策略：饱和运算或动态缩放


### 9.2.4 自适应相似度阈值


自适应阈值可以根据局部图像特性调整降噪强度：


**噪声估计**：
\(\sigma^2_{noise} = \text{median}(|W_h * I|) / 0.6745\)


其中 $W_h$ 是高通滤波器，用于提取噪声成分。


**自适应滤波参数**：
\(h_{adaptive} = h_{base} \cdot f(\sigma_{local}, \sigma_{noise})\)


调整函数 $f$ 的设计：


- 平坦区域：增大 $h$，加强降噪
- 纹理区域：减小 $h$，保护细节
- 边缘区域：方向性调整


**硬件实现要点**：


1. 局部统计模块：计算局部方差
2. 查找表映射：方差到参数的映射
3. 参数平滑：避免块效应


## 9.3 搜索窗口优化：自适应搜索策略


### 9.3.1 固定窗口 vs 自适应窗口


**固定窗口策略**：


- 典型大小：21×21 到 35×35
- 优点：硬件实现简单，延迟固定
- 缺点：计算冗余，边缘区域效果差


**自适应窗口策略**：


1. **基于纹理的窗口调整**：

```
纹理复杂度 T = Σ|∇I|² / Area

窗口大小：
- T < T_low：  使用大窗口 (35×35)
- T_low < T < T_high：使用中窗口 (21×21)
- T > T_high： 使用小窗口 (11×11)
```


2. **基于相似度的早期终止**： 设置相似度阈值
3. 找到足够相似块后停止搜索
4. 动态调整搜索半径


**硬件架构对比**：


```
固定窗口：
┌────────────────┐
│  固定大小缓存   │ → 简单控制逻辑
└────────────────┘

自适应窗口：
┌────────────────┐
│  可变大小缓存   │ → 复杂控制逻辑

└────────────────┘
```
