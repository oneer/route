# ISP Tutorial 学习区

来源：[ISP IP设计教程：从算法到RTL实现](https://zsc.github.io/isp_tutorial/)

这个文件夹用于单独沉淀网页教程的学习记录。它不直接替代 `soft_isp_stage1` 或 `ai_isp_stage2`，而是作为独立的 ISP 学习教程：先按章节理解概念、算法、硬件约束和工程问题，再把可验证的部分迁移到后续实验或实现中。

## 文件结构

- [full_content_index.md](full_content_index.md)：35 章完整正文内容索引，优先从这里进入学习。
- [tutorial_quality_standard.md](tutorial_quality_standard.md)：本学习区采用的“初学者友好教程”完善标准。
- [research_bibliography.md](research_bibliography.md)：用于扩展 35 章教程的网络资料、论文、开源项目、官方文档和专业书籍线索。
- [full_chapters/](full_chapters/)：35 章完整 Markdown 正文；每章在保留原网页正文的基础上，补充面向初学者的详细解释、原理拆解、工程问题、实验建议、自测题和参考资料。

## 使用方式

1. 从 [完整章节内容索引](full_content_index.md) 进入任意章节。
2. 先看 [初学者友好 ISP 教程完善标准](tutorial_quality_standard.md)，明确每章应该学到什么程度。
3. 优先阅读 `full_chapters/chapterXX-*.md`；每章正文前部是扩展后的学习教程，后部保留原网页正文内容。
4. 如需对照原始网页排版、表格或链接，打开章节顶部的原网页来源链接。
5. 每章至少沉淀三类内容：
   - 关键概念：本章真正要掌握的术语、算法或架构。
   - 工程问题：如果要实现或验证，会遇到哪些输入、约束、误差和失败现象。
   - 学习闭环：能否通过实验、自测题、验收标准说明自己已经理解。

## 当前学习假设

- 目标不是简单搬运网页，而是建立可复习、可实验、可扩展的学习教程。
- 章节顺序以网页首页给出的 35 章结构为准。
- 本学习区独立于项目实现目录，重点关注“算法原理 -> 工程实现 -> 验证指标”的闭环。

## 推荐节奏

- 第 1-16 章：传统 ISP 基础，包括传感器、Raw 前端、去马赛克、降噪、色彩、3A、硬件架构等。
- 第 17-27 章：产业架构与应用场景，包括手机、车载、专业相机、消费电子、安防和视频 ISP。
- 第 28-31 章：AI-ISP、深度学习增强模块、ISP/GPU/视频编解码器架构对比。
- 第 32-35 章：验证方法学、后端实现、系统集成和技术趋势。
