# 可落地 RAW 体检与画质诊断补强

这份报告只使用仓库现有 DNG，不依赖手机、色卡、平场箱或工业测试软件。目标不是伪装工业 IQ，而是把当前能做扎实的部分沉淀成可复现实验：RAW 体检、近似 IQ 指标、ROI 可视化、DPC 注入/参数扫描和 AWB baseline 对比。

## 学习目标

1. 拿到一张 RAW 后，先检查 black/white level、clipping、暗部/中间调/高光 ROI，而不是直接跑后处理。
2. 在没有 flat-field / slanted-edge chart 的情况下，只输出相对诊断指标，并明确它们不能替代实验室 IQ。
3. 用注入坏点验证 DPC 的 recall / false positive tradeoff，而不是只看一张修复图。
4. 用多种 AWB baseline 暴露场景假设差异，为后续真实 3A 学习做入口。

## 边界声明

- `SNR` 是自然图 ROI 上的相对诊断值，不等于实验室 flat-field SNR。
- `dynamic range` 使用 white level、black level 和暗部 ROI std 估算，不等于 sensor 标定 DR。
- `MTF50 proxy` 是边缘 crop 的频域近似，不等于 slanted-edge chart MTF。
- AWB 对比只说明不同 baseline 在现有场景上的中性候选像素误差，不等于产品 3A。
- DPC 注入验证能证明算法可找回人工 hot/dead pixel，不能证明工厂 defect map 或真实坏点覆盖率。

## 学习复盘

### 已经补上的能力

- 从单纯 PSNR/SSIM，扩展到 RAW clipping、ROI SNR proxy、DR proxy、edge sharpness proxy。
- 从“DPC 看起来修了”，扩展到人工 hot/dead pixel 注入、召回率、额外检测和参数扫描。
- 从单一 Gray World，扩展到 Gray World / White Patch / Shades-of-Gray 的同场景对比。
- 每张 DNG 都有直方图和 ROI 标注图，可以在面试里按图解释“先看 RAW，再谈算法”。

### 仍然不能证明的能力

- 没有真实 dark frame / flat-field，因此不能给出实验室 SNR、PRNU、DSNU 或真实 LSC 标定结论。
- 没有 slanted-edge chart，因此 MTF50 仍是 proxy，不是标准 MTF。
- 没有 ColorChecker，因此 AWB/CCM 只能做中性候选像素诊断，不能声明颜色准确性。
- 没有时序 RAW/burst，因此还不能讨论视频 3A 稳定性或多帧坏点策略。

## 面试可讲结论

我没有把公开 DNG 包装成工业测试数据，而是先建立了一套可复现 RAW 体检流程：读取 metadata 后检查 black/white level 和 clipping，自动选 dark/midtone/highlight/edge ROI，输出相对 SNR、DR 和边缘清晰度 proxy。对于 DPC，我用人工注入 hot/dead pixel 做 recall 和 false positive 分析，并扫描 `mad_k` 解释阈值取舍；对于 AWB，我比较 Gray World、White Patch 和 Shades-of-Gray，说明不同场景假设会导致不同 gain。这个项目不能证明量产 tuning，但能证明我知道真实 IQ 证据需要什么、现有数据能验证什么、以及下一步该补什么数据。
