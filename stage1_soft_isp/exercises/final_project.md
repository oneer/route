# 阶段一独立毕业任务

在新的空目录中实现，不复制 `soft_isp/` 源码。

## 必做功能

```text
DNG -> BLC -> Bilinear Demosaic -> Gray World AWB
    -> 3x3 CCM -> sRGB/简化 Gamma -> PNG
```

- YAML 或等价配置开关；
- 保存至少 3 个中间结果；
- 至少 3 张不同场景 DNG；
- 至少 6 个合成单元测试；
- 一组参数预测实验；
- 一个失败案例；
- 一份两到四页报告。

## 验收问题

1. 每一步的输入、输出、shape、dtype、值域是什么？
2. 为什么顺序这样安排？
3. 哪一步最容易造成不可逆信息损失？
4. 输出为何与 rawpy 不同？
5. 若进入阶段二，哪些数据可以作为模型输入和目标？

## 禁止作为完成证据

- 只展示最终 PNG；
- 只复制现有指标；
- 没有测试；
- 没有 Git 迭代；
- 不能解释一个失败案例。
