# 阶段一练习入口

练习优先于查看 `reports/` 中的现成结论。完成任务后再用现有实现和报告复盘。

| 顺序 | 任务 | 验收 |
|---:|---|---|
| 1 | `week1_raw_contract.md` | 能解释一张陌生 DNG 的 metadata、shape、dtype、值域 |
| 2 | `week2_dpc_injection.py` | 完成坏点注入，计算 recall 和 false positives |
| 3 | `week3_demosaic_todo.py` | 独立补全最小 bilinear demosaic |
| 4 | `debug_challenges.md` | 定位至少 4 类预置问题 |
| 5 | `final_project.md` | 脱离现有答案完成简化 Pipeline |

规则：

- 先写预测，再运行；
- 禁止直接复制 `soft_isp/` 实现；
- 每次提交包含测试或可验证输出；
- 完成标准以断言、指标和解释为准，不以代码行数为准。
