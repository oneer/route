# 阶段一前置知识与自测

阶段一不是 Python 零基础课程。正式开始前，应能独立完成下面的最小任务；不会的部分先补，不要一边猜语法一边学 ISP。

## 必须掌握

1. Python 函数、字典、列表、异常和 `Path`。
2. NumPy 的 `shape`、`dtype`、切片、布尔 mask、broadcast 和矩阵乘法。
3. 图像数组常见布局：`H×W`、`H×W×3`。
4. `uint16`、`float32`、`uint8` 的范围，以及先转有符号/浮点再做减法的原因。
5. 均值、标准差、中位数、百分位数的直觉。
6. Git 的 `status`、`diff`、`add`、`commit`。

## 五题自测

1. 给定 `raw = np.arange(16).reshape(4, 4)`，写出偶数行偶数列的结果。
2. 解释为什么 `np.uint16(10) - np.uint16(20)` 可能不是 `-10`。
3. 给定 `rgb.shape == (100, 200, 3)`，说明每个维度的含义。
4. 不运行代码，预测 `rgb * np.array([2, 1, 0.5])` 如何广播。
5. 解释 `rgb @ matrix.T` 中转置的作用。

## 通过标准

- 能在 20 分钟内完成前四题并用一个小脚本验证；
- 能解释答案，而不是只贴运行结果；
- 不通过时，先查 NumPy 官方 quickstart 或一本基础 Python/NumPy 教程。
