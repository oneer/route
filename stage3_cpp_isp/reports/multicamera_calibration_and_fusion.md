# Multi-camera aligned fusion core

## Implemented scope

- Dependency-free least-squares planar homography estimation.
- Reprojection mean/RMS/max metrics and threshold-returning CLI.
- Caller-owned inverse-mapped bilinear perspective warp.
- OpenCV `findHomography` reference alignment on a seven-point synthetic set.
- Per-channel overlap color-gain estimation.
- Gain application into a caller-owned output buffer; no per-frame allocation.
- Feather blending for already-aligned planar RGB images.
- Mean overlap alignment error, mean color delta, and seam delta.
- CTest coverage for homography recovery, degenerate geometry rejection,
  identity warp, color-match improvement, blend boundaries, and invalid ranges.
- Release benchmark for 1080P and 4K.

This is deliberately narrower than a full synchronized stereo pipeline. Camera
intrinsic/extrinsic calibration, lens distortion correction, capture
synchronization, and real parallax failure cases still require captured
calibration/scene data.

## Synthetic geometry correctness

- Correspondences: 7 points generated by a known projective transform.
- C++ mean/max reprojection error: `9.20e-14 / 1.88e-13 px`.
- Maximum normalized matrix difference vs OpenCV: `3.25e-7` (threshold `1e-6`, pass).
- Synthetic CPF32 fusion output is checked against a NumPy reference with a
  `1e-6` maximum-absolute-error threshold; measured max/mean error is
  `2.38e-7 / 6.77e-8` (pass).
- The threshold in the Capstone multicamera contract remains `1.0 px` for a
  future captured static-pair evaluation; this synthetic check is only a
  numerical implementation alignment.

## Verification

- Compiler: MSVC 19.51.36248, C++17, Release, /O2, /W4, /permissive-, /utf-8.
- CPU: 12th Gen Intel Core i3-12100F.
- I/O: excluded.
- Input: synthetic planar RGB float32, three channels.
- Buffer policy: inputs, matched buffer, and output allocated before timing.
- Warm-up: 1 run.
- Timed runs: 20.
- CTest: 14/14 passed, including camera calibration and image fusion.

not include calibration, warping, image decode, file I/O, or memory allocation.
